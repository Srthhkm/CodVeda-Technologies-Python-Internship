# CodVeda-Technologies-Python-Internship

This repository contains Python projects completed as part of the **Codveda Technologies Python Development Internship**.  
The tasks are organized level-wise and demonstrate Python fundamentals, intermediate concepts, and advanced problem-solving skills.

---

## 📂 Project Structure

### 🔹 Level 1 – Beginner
- **Task 1: Simple Calculator**  
  A command-line calculator supporting basic arithmetic operations with error handling.

- **Task 2: Number Guessing Game**  
  A Python game where the user guesses a randomly generated number with limited attempts.

---

### 🔹 Level 2 – Intermediate
- **Task 1: To-Do List Application**  
  A command-line based to-do list application with file-based persistent storage.

- **Task 3: API Integration (Weather App)**  
  A Python script that fetches and displays real-time weather information using an external API.

---

### 🔹 Level 3 – Advanced
- **Task 2: File Encryption and Decryption**  
  A Python program that encrypts and decrypts text files using the Caesar Cipher technique.

- **Task 3: N-Queens Problem**  
  A backtracking-based solution to the classic N-Queens problem for an N×N chessboard.

---

## 🛠️ Technologies Used
- Python 3
- Standard Python libraries
- File handling
- API integration
- Backtracking algorithm
