# File Encryption and Decryption

A Python program that encrypts and decrypts text files using the Caesar Cipher technique.

## Features
- Encrypts text files using a shift-based cipher
- Decrypts encrypted files back to original form
- Uses file handling for input and output
- Simple and secure logic implementation

## How to Run
1. Open the folder containing `encrypt_decrypt.py`
2. Run the following command:

```bash
python encrypt_decrypt.py
