# N-Queens Problem

A Python program that solves the N-Queens problem using the backtracking algorithm.

## Problem Statement
Place N queens on an N×N chessboard such that no two queens attack each other.

## Features
- Uses backtracking algorithm
- Ensures no queens share the same row, column, or diagonal
- Displays one valid solution

## How to Run
1. Open the folder containing `n_queens.py`
2. Run the following command:

```bash
python n_queens.py
